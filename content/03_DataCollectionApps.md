# Comparing Data Collection Applications

Data collection applications are designed to help users gather, organize, and share information in the field. While ArcGIS Field Maps, ArcGIS Survey123, ArcGIS QuickCapture, and QField all support field data collection, each application is designed for different types of workflows and users.

## ArcGIS Field Maps

ArcGIS Field Maps is a map-centric data collection application. It combines interactive maps with customizable forms, allowing users to view their location, collect features, update existing records, and navigate to sites in real time. Field Maps is particularly useful when data collection requires precise geographic information and users need to see collected information displayed on a map. It also supports offline data collection, making it a strong choice for fieldwork in areas with limited internet connectivity.

Best for: Mapping assets, environmental monitoring, infrastructure inspections, and projects where location is the primary focus.

## ArcGIS QuickCapture

ArcGIS QuickCapture is designed for rapid data collection with minimal user interaction. Instead of completing detailed forms, users tap large buttons that instantly capture predefined information, including location, photos, and timestamps. This makes QuickCapture ideal for collecting large volumes of observations while moving, such as from a vehicle, bicycle, or aircraft.

Best for: Road assessments, wildlife observations, utility inspections, and situations where speed and simplicity are more important than detailed data entry.

## ArcGIS Survey123

ArcGIS Survey123 is a form-centric data collection application that focuses on collecting survey responses through structured questionnaires. Unlike Field Maps, respondents can often complete surveys through a web link without needing an ArcGIS account or mobile app, making it suitable for public engagement and large-scale surveys. Survey123 supports advanced question types, logic rules, and built-in reporting tools, helping users collect consistent and detailed information.

Best for: Surveys, questionnaires, interviews, community feedback, and research projects that require standardized responses.

## QField

QField is an open-source mobile data collection application built to work with QGIS projects. Like Field Maps, it is map-focused and allows users to view maps, edit features, collect GPS data, and work offline. Because it integrates with QGIS rather than ArcGIS, QField is often used by organizations that prefer open-source GIS solutions. While it provides many powerful data collection capabilities, it may require more technical setup compared to ArcGIS applications.

Best for: Organizations using QGIS, open-source GIS projects, and users who need customizable field mapping tools without relying on the ArcGIS platform.

## Similarities

- Allow users to collect geographic data in the field.
- Support GPS location capture.
- Can attach photos and other media to records.
- Offer offline data collection capabilities.
- Help streamline the transfer of field data into GIS databases for analysis and mapping.

## Key Differences

| Application      | Primary Focus                            | User Experience                  | Typical Audience                                   |
| ---------------- | ---------------------------------------- | -------------------------------- | -------------------------------------------------- |
| **Field Maps**   | Map-based data collection and editing    | Interactive maps with forms      | GIS professionals and field crews                  |
| **Survey123**    | Survey and questionnaire data collection | Form-driven surveys              | Researchers, educators, and public respondents     |
| **QuickCapture** | Rapid observation collection             | One-tap button interface         | Mobile workers collecting high volumes of data     |
| **QField**       | Open-source map-based field mapping      | QGIS project editing and mapping | QGIS users and organizations using open-source GIS |
